# 방문자 카운트 이식 가이드 (바이란 라운지 방식)

> **다른 사이트에 적용할 때 Claude에게 이렇게 말하면 돼요**
> "이 문서대로 우리 사이트에 방문자 카운트 붙여줘. 관리 화면에 당일 / 최근 7일 / 전체로 '방문한 사람(기기 기준)', '총 방문 횟수', '화면 연 횟수', '어느 플랫폼에서 왔나'가 보이게. 운영자 기기랑 봇은 빼고."
> 그리고 이 파일을 같이 붙여 넣으세요.

기준 구현: byranmedia.com (Express + EJS + PostgreSQL). Next.js나 Supabase 사이트는 맨 아래 메모를 보세요.

---

## 1. 무엇을 어떻게 세나

| 숫자 | 뜻 | 세는 법 |
|---|---|---|
| **방문한 사람** | 기기(브라우저) 1대 = 1명 | 하루에 기기마다 한 줄. `count(DISTINCT vid)` |
| **총 방문 횟수** | 들락날락 전부 | 같은 기기라도 **30분 넘게 쉬었다가** 다시 오면 +1 |
| **화면 연 횟수** | 페이지뷰 | 화면(HTML)을 열 때마다 +1 |
| **IP 수** | 참고용 | 하루 기록에 처음 IP를 같이 저장 |
| **플랫폼** | 스레드·인스타·카톡·네이버·구글 등 | 링크 표시(`?from=`) → 앱 안 브라우저 이름 → 들어오기 전 주소 순으로 판단 |

**빼는 것**
- **봇**: 이름을 밝히는 봇은 User-Agent로 차단해요. 브라우저인 척하는 봇은 "사람 확인 신호"로 걸러요. 화면을 열고 스크롤·터치·클릭을 하거나 6초 넘게 머문 기기만 사람으로 세요.
- **운영자 기기**: 운영자로 로그인한 적 있는 기기는 관리 통계에서 빠져요. 카톡·스레드 앱 안 브라우저처럼 로그인을 안 하는 곳은 "운영자 전용 주소"를 한 번 열면 빠져요.
- 이미지·CSS·API·관리 화면·에러 화면은 안 세요.

**홈에 공개하는 '오늘 방문' 숫자**는 많아 보이게 화면 연 횟수 합계를 써요. 중복이 포함되고 운영자 방문도 들어가요. 관리 통계와는 따로예요.

**날짜**는 한국 시간(Asia/Seoul) 자정 기준이에요.

## 2. 동작 순서 (한눈에)

```
화면 요청(GET, HTML) ─▶ 봇 UA면 무시
        │
        ├─ 쿠키 bv(기기 이름표, 400일) 없으면 새로 발급
        ├─ 운영자 로그인 중이면 이 기기를 owner_devices에 등록
        └─ 응답이 끝나면(200·HTML일 때만) site_visits (day, vid) 한 줄 UPSERT
              · 처음이면 views=1, visits=1
              · 이미 있으면 views+1, 마지막 방문 후 30분 넘었으면 visits+1

화면 안 스크립트(hi.js) ─▶ 스크롤·터치·클릭 또는 6초 머묾 ─▶ POST /v/hi
        └─ 오늘 이 기기 줄을 human = true

관리 통계 = site_visits_x 뷰 (human = true 이고 운영자 기기가 아닌 줄만)
```

## 3. DB (PostgreSQL)

```sql
-- 하루에 기기 1대당 한 줄
CREATE TABLE IF NOT EXISTS site_visits (
  day        DATE        NOT NULL,              -- 한국 날짜
  vid        VARCHAR(40) NOT NULL,              -- 기기 이름표 (쿠키 bv)
  user_id    INT,                               -- 그날 로그인했으면 회원 번호
  views      INT         NOT NULL DEFAULT 1,    -- 화면 연 횟수
  visits     INT         NOT NULL DEFAULT 1,    -- 방문 횟수 (30분 쉬면 +1)
  first_path VARCHAR(200),                      -- 처음 들어온 화면
  ref_host   VARCHAR(120),                      -- 들어오기 전 사이트
  source     VARCHAR(20),                       -- 플랫폼 (threads, instagram, kakaotalk ...)
  ip         VARCHAR(64),
  human      BOOLEAN     NOT NULL DEFAULT false,-- 사람 확인 신호를 받았는지
  last_at    TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (day, vid)
);
CREATE INDEX IF NOT EXISTS idx_site_visits_day ON site_visits (day);
CREATE INDEX IF NOT EXISTS idx_site_visits_user ON site_visits (user_id) WHERE user_id IS NOT NULL;

-- 운영자 기기 (관리 통계에서 뺌)
CREATE TABLE IF NOT EXISTS site_owner_devices (
  vid        VARCHAR(40) PRIMARY KEY,
  user_id    INT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 관리 통계용 뷰: 사람 확인 + 운영자 기기 제외
-- (컬럼을 나중에 추가하면 DROP 후 다시 만들어야 해서, 마이그레이션 파일 맨 아래에 두기)
DROP VIEW IF EXISTS site_visits_x;
CREATE VIEW site_visits_x AS
  SELECT v.* FROM site_visits v
   WHERE v.human
     AND NOT EXISTS (SELECT 1 FROM site_owner_devices o WHERE o.vid = v.vid);

-- (선택) 회원 '최근 방문' 시각
ALTER TABLE users ADD COLUMN IF NOT EXISTS last_seen_at TIMESTAMPTZ;
```

## 4. 서버 코드 — `visits.js` (Express)

`db.query(sql, params)`를 쓰는 pg Pool 기준이에요. `req.user`(로그인 회원, `role === 'admin'`이면 운영자)는 사이트에 맞게 바꾸세요.

```js
/* 방문자 세기 — 기기(쿠키) 1대 = 1명, 30분 쉬면 방문 +1, 봇·운영자 제외 */
const crypto = require('crypto');
const db = require('./db');

const PROD = process.env.NODE_ENV === 'production';
const DAY = `(now() AT TIME ZONE 'Asia/Seoul')::date`;
const COOKIE = 'bv';
const VID_RE = /^[a-f0-9]{16,40}$/;

// 안 세는 주소 (관리·API·로그인 콜백·파일)
const SKIP_PATH = /^\/(admin|api\/|auth\/|v\/|healthz|favicon|manifest|robots|sitemap)|\.[a-z0-9]{2,5}$/i;
// 봇: 이름 밝히는 것 + 브라우저인 척하는 흔한 가짜 (옛날 크롬<100·파이어폭스<90, 텐센트 크롤러 iPhone OS 13_2_3 등)
const BOT = /bot|crawl|spider|slurp|preview|scrap|facebookexternalhit|kakaotalk-scrap|daumoa|yeti|curl|wget|python|go-http|java\/|headless|lighthouse|monitor|uptime|axios|node-fetch|checker|scanner|leads|httpclient|okhttp|libwww|compatible;|iPhone OS 13_2_3|Chrome\/[1-9]\d\.|Firefox\/[1-8]\d\.|PhantomJS|Puppeteer|Playwright|Selenium/i;

function readCookie(req, name) {
  const m = String(req.headers.cookie || '').match(new RegExp('(?:^|;\\s*)' + name + '=([^;]+)'));
  return m ? decodeURIComponent(m[1]) : '';
}
function setVidCookie(res, vid) {
  res.cookie(COOKIE, vid, { maxAge: 1000 * 60 * 60 * 24 * 400, httpOnly: true, sameSite: 'lax', secure: PROD });
}

/* ---------- 플랫폼 ---------- */
const SOURCES = {
  threads: '🧵 스레드', instagram: '📸 인스타그램', facebook: '📘 페이스북', kakaotalk: '💬 카카오톡',
  naver: '🟢 네이버', google: '🔎 구글', youtube: '▶️ 유튜브', daum: '🔵 다음', x: '✖️ X(트위터)',
  tiktok: '🎵 틱톡', band: '🟩 밴드', line: '🟢 라인', direct: '🔗 직접 들어옴 · 즐겨찾기', other: '🌐 기타 사이트',
};
const SRC_WORDS = [
  ['threads', /threads/], ['instagram', /insta|ig\b/], ['facebook', /facebook|\bfb\b/], ['kakaotalk', /kakao|카톡/],
  ['naver', /naver|블로그|blog/], ['google', /google/], ['youtube', /youtube|yt\b/], ['daum', /daum/],
  ['x', /twitter|^x$/], ['tiktok', /tiktok/], ['band', /band/], ['line', /^line/],
];
function refHost(req) {
  try {
    const h = new URL(req.get('referer') || '').host.replace(/^(www|m)\./, '').toLowerCase();
    const own = String(req.get('host') || '').replace(/^www\./, '').toLowerCase();
    return h && h !== own ? h.slice(0, 120) : null;
  } catch (e) { return null; }
}
function sourceOf(req, host) {
  // 1) 링크에 붙인 표시: ?from=threads, ?utm_source=instagram
  const tag = String((req.query && (req.query.from || req.query.utm_source || req.query.ref)) || '').toLowerCase().slice(0, 30);
  if (tag) { const hit = SRC_WORDS.find((w) => w[1].test(tag)); return hit ? hit[0] : 'other'; }
  // 2) 앱 안 브라우저 (주소를 안 넘겨 줘도 앱 이름은 보임)
  const ua = req.get('user-agent') || '';
  if (/Barcelona|Threads/i.test(ua)) return 'threads';
  if (/Instagram/i.test(ua)) return 'instagram';
  if (/FBAN|FBAV|FB_IAB|FBIOS/i.test(ua)) return 'facebook';
  if (/KAKAOTALK/i.test(ua)) return 'kakaotalk';
  if (/NAVER\(inapp|NAVER\//i.test(ua)) return 'naver';
  if (/DaumApps/i.test(ua)) return 'daum';
  if (/\bBAND\//i.test(ua)) return 'band';
  if (/\bLine\//i.test(ua)) return 'line';
  if (/musical_ly|TikTok|BytedanceWebview/i.test(ua)) return 'tiktok';
  // 3) 들어오기 전 주소
  const h = host || '';
  if (!h) return 'direct';
  if (/threads\.(net|com)$/.test(h)) return 'threads';
  if (/instagram\.com$/.test(h)) return 'instagram';
  if (/(facebook\.com|fb\.me)$/.test(h)) return 'facebook';
  if (/kakao/.test(h)) return 'kakaotalk';
  if (/naver\./.test(h)) return 'naver';
  if (/(^|\.)google\./.test(h)) return 'google';
  if (/(youtube\.com|youtu\.be)$/.test(h)) return 'youtube';
  if (/daum\.net$/.test(h)) return 'daum';
  if (/(^|\.)(t\.co|x\.com|twitter\.com)$/.test(h)) return 'x';
  if (/tiktok\.com$/.test(h)) return 'tiktok';
  if (/band\.us$/.test(h)) return 'band';
  return 'other';
}
// 프록시(레일웨이 등) 뒤라면 X-Real-IP → X-Forwarded-For 첫 번째 → req.ip
function clientIp(req) {
  const real = String(req.get('x-real-ip') || '').trim();
  if (real) return real.slice(0, 64);
  const xff = String(req.get('x-forwarded-for') || '').split(',')[0].trim();
  return (xff || String(req.ip || '')).replace(/^::ffff:/, '').slice(0, 64) || null;
}

/* ---------- 1) 화면 열 때마다 기록 (미들웨어) ---------- */
function track(req, res, next) {
  if (req.method !== 'GET' || SKIP_PATH.test(req.path)) return next();
  const ua = req.get('user-agent') || '';
  if (!ua || BOT.test(ua)) return next();

  let vid = readCookie(req, COOKIE);
  if (!VID_RE.test(vid)) { vid = crypto.randomBytes(12).toString('hex'); setVidCookie(res, vid); }
  req.vid = vid;

  if (req.user && req.user.role === 'admin') {
    db.query(`INSERT INTO site_owner_devices (vid, user_id) VALUES ($1,$2) ON CONFLICT (vid) DO NOTHING`, [vid, req.user.id]).catch(() => {});
  }
  const ref = refHost(req);
  const src = sourceOf(req, ref);

  res.on('finish', () => {
    if (res.statusCode >= 400) return;
    if (!/text\/html/.test(String(res.get('content-type') || ''))) return;
    if (req.user) {
      db.query(`UPDATE users SET last_seen_at = now() WHERE id = $1 AND (last_seen_at IS NULL OR last_seen_at < now() - interval '5 minutes')`, [req.user.id]).catch(() => {});
    }
    db.query(
      `INSERT INTO site_visits (day, vid, user_id, first_path, ref_host, ip, last_at, source)
       VALUES (${DAY}, $1, $2, $3, $4, $5, now(), $6)
       ON CONFLICT (day, vid) DO UPDATE SET
         views   = site_visits.views + 1,
         visits  = site_visits.visits + CASE WHEN site_visits.last_at IS NULL OR now() - site_visits.last_at > interval '30 minutes' THEN 1 ELSE 0 END,
         last_at = now(),
         user_id = COALESCE(site_visits.user_id, EXCLUDED.user_id),
         ip      = COALESCE(site_visits.ip, EXCLUDED.ip)`,
      [vid, req.user ? req.user.id : null, req.path.slice(0, 200), ref, clientIp(req), src]
    ).catch((e) => console.error('[방문 기록]', e.message));
  });
  next();
}

/* ---------- 2) 사람 확인 신호 (POST /v/hi) ---------- */
function hi(req, res) {
  res.status(204).end();
  const ua = req.get('user-agent') || '';
  const vid = readCookie(req, COOKIE);
  if (!ua || BOT.test(ua) || !VID_RE.test(vid)) return;
  const mark = () => db.query(`UPDATE site_visits SET human = true WHERE day = ${DAY} AND vid = $1`, [vid]).then((r) => r.rowCount);
  // 기록 줄이 아직 안 생겼으면 3초 뒤 한 번 더
  mark().then((n) => { if (!n) setTimeout(() => mark().catch(() => {}), 3000); }).catch(() => {});
}

/* ---------- 3) 운영자 전용 주소 (GET /v/me/:key) ---------- */
// 카톡·스레드 앱 안 브라우저에서 이 주소를 한 번 열면 그 브라우저도 운영자 기기 → 통계에서 빠짐
function ownerKey() {
  return crypto.createHmac('sha256', String(process.env.SESSION_SECRET || 'change-me')).update('owner-device').digest('hex').slice(0, 20);
}
function markOwner(req, res) {
  if (req.params.key !== ownerKey()) return res.redirect('/');
  let vid = readCookie(req, COOKIE);
  if (!VID_RE.test(vid)) { vid = crypto.randomBytes(12).toString('hex'); setVidCookie(res, vid); }
  db.query(`INSERT INTO site_owner_devices (vid) VALUES ($1) ON CONFLICT (vid) DO NOTHING`, [vid])
    .then(() => res.type('html').send('<meta name="viewport" content="width=device-width,initial-scale=1"><p style="font:16px sans-serif;padding:40px;text-align:center">✅ 이 브라우저는 운영자 기기로 기억돼요. 관리 통계에서 빠져요.<br><br><a href="/">홈으로</a></p>'))
    .catch(() => res.redirect('/'));
}

/* ---------- 4) 숫자 꺼내기 ---------- */
// r: 'today' | '7d' | 'all'. prev=true면 바로 앞 같은 길이 기간 (▲▼ 비교용)
function range(r, prev = false) {
  if (r === 'all') return prev ? null : 'true';
  if (r === '7d') return prev ? `day BETWEEN ${DAY} - 13 AND ${DAY} - 7` : `day >= ${DAY} - 6`;
  return prev ? `day = ${DAY} - 1` : `day = ${DAY}`;
}
async function summary(r = 'today') {
  const one = async (cond) => {
    if (!cond) return null;
    const { rows } = await db.query(
      `SELECT count(DISTINCT vid)::int AS people, count(DISTINCT ip)::int AS ips,
              COALESCE(sum(visits),0)::int AS visits, COALESCE(sum(views),0)::int AS views
         FROM site_visits_x WHERE ${cond}`);
    return rows[0];
  };
  const [cur, prev] = await Promise.all([one(range(r)), one(range(r, true))]);
  return { ...cur, prev };
}
// 최근 N일 날짜별 (그래프·달력용)
async function daily(days = 14) {
  const { rows } = await db.query(
    `WITH d AS (SELECT generate_series(${DAY} - ($1::int - 1), ${DAY}, interval '1 day')::date AS day)
     SELECT d.day::text AS day,
            (SELECT count(DISTINCT vid) FROM site_visits_x v WHERE v.day = d.day)::int AS people,
            (SELECT COALESCE(sum(visits),0) FROM site_visits_x v WHERE v.day = d.day)::int AS visits,
            (SELECT COALESCE(sum(views),0)  FROM site_visits_x v WHERE v.day = d.day)::int AS views
       FROM d ORDER BY d.day DESC`, [days]);
  return rows;
}
// 플랫폼별 (사람·방문 횟수)
async function platforms(r = 'today') {
  const { rows } = await db.query(
    `SELECT COALESCE(source,'direct') AS src, count(DISTINCT vid)::int AS people, COALESCE(sum(visits),0)::int AS visits
       FROM site_visits_x WHERE ${range(r)} GROUP BY 1 ORDER BY people DESC`);
  return rows.map((x) => ({ ...x, label: SOURCES[x.src] || x.src }));
}
// 홈 공개용 '오늘 방문' — 화면 연 횟수 합계 (중복·운영자 포함). 1분 캐시
let pub = { at: 0, n: 0 };
async function publicToday() {
  if (Date.now() - pub.at < 60000) return pub.n;
  const { rows } = await db.query(`SELECT COALESCE(sum(views),0)::int AS n FROM site_visits WHERE day = ${DAY}`);
  pub = { at: Date.now(), n: rows[0].n };
  return pub.n;
}

module.exports = { track, hi, markOwner, ownerKey, summary, daily, platforms, publicToday, SOURCES, readCookie, VID_RE, DAY };
```

## 5. 사람 확인 스크립트 — `public/js/hi.js`

모든 화면의 `</body>` 바로 위에 `<script src="/js/hi.js" defer></script>`를 넣어요. 공통 레이아웃이 여러 개면 전부 넣어야 해요.

```js
/* 스크롤·터치·클릭·키보드 중 하나를 하거나 화면을 6초 넘게 보면 한 번만 알림 (봇은 대부분 안 함) */
(function () {
  var sent = false, t = null, evs = ['scroll', 'touchstart', 'pointerdown', 'mousemove', 'keydown', 'wheel'];
  function send() {
    if (sent) return; sent = true;
    evs.forEach(function (e) { window.removeEventListener(e, send, true); });
    if (t) clearTimeout(t);
    try {
      if (navigator.sendBeacon) navigator.sendBeacon('/v/hi', '');
      else fetch('/v/hi', { method: 'POST', credentials: 'same-origin', keepalive: true });
    } catch (e) {}
  }
  evs.forEach(function (e) { window.addEventListener(e, send, { capture: true, passive: true }); });
  function arm() { if (!sent && document.visibilityState === 'visible' && !t) t = setTimeout(send, 6000); }
  document.addEventListener('visibilitychange', function () {
    if (document.visibilityState !== 'visible' && t) { clearTimeout(t); t = null; } else arm();
  });
  arm();
})();
```

## 6. 연결 (app.js)

순서가 중요해요. **로그인 사용자 불러오기(loadUser) 다음, 라우트 앞**에 둬야 해요.

```js
const V = require('./visits');
app.set('trust proxy', 1);                 // 프록시 뒤라면
app.use(loadUser);                         // req.user 채우는 미들웨어 (사이트마다 다름)
app.post('/v/hi', V.hi);                   // 사람 확인 신호
app.get('/v/me/:key', V.markOwner);        // 운영자 기기 등록 주소
app.use(V.track);                          // 방문 기록
// ... 라우트들
```

관리 화면에는 운영자 전용 주소를 보여 주세요. 접어 두는 칸 안에 넣고 "남에게 보내지 마세요"라고 적어 두면 좋아요.
```js
const ownerUrl = `${process.env.BASE_URL}/v/me/${V.ownerKey()}`;
```

## 7. 관리 화면에 보여 줄 것 (바이란 기준)

- 탭: **당일 / 최근 7일 / 전체**
- 큰 숫자 카드:
  - **방문한 사람**(기기 기준)

## 8. (보너스) 글·상품 조회수도 "하루 기기 1대당 1번"

새로고침이나 재방문으로는 안 올라가요. 다음 날 다시 보면 +1이에요.

```sql
CREATE TABLE IF NOT EXISTS site_view_log (
  kind    CHAR(1)     NOT NULL,   -- 예: p=상품/프롬프트, c=글
  item_id INT         NOT NULL,
  day     DATE        NOT NULL,
  who     VARCHAR(60) NOT NULL,   -- 'd:<기기>' 또는 'u:<회원번호>'
  PRIMARY KEY (kind, item_id, day, who)
);
DELETE FROM site_view_log WHERE day < CURRENT_DATE - 3;  -- 부팅할 때 오래된 기록 정리
```
```js
// 상세 화면 라우트에서: countView('p', 'products', id, req)
function countView(kind, table, id, req) {
  const c = readCookie(req, 'bv') || req.vid || '';
  const who = VID_RE.test(c) ? 'd:' + c : req.user ? 'u:' + req.user.id : null;
  if (!who) return Promise.resolve(false);           // 쿠키 없는 봇은 안 셈
  return db.query(
    `WITH ins AS (INSERT INTO site_view_log (kind, item_id, day, who) VALUES ($1,$2,${DAY},$3) ON CONFLICT DO NOTHING RETURNING 1)
     UPDATE ${table} SET views = views + 1 WHERE id = $2 AND EXISTS (SELECT 1 FROM ins)`,
    [kind, id, who]).then((r) => r.rowCount > 0).catch(() => false);
}
```
`table`에는 코드에 고정된 테이블 이름만 넣으세요. 사용자 입력을 넣으면 안 돼요.

## 9. 꼭 알아둘 점

1. **쿠키를 안 받는 봇**은 들어올 때마다 "새 기기"가 돼서 숫자가 크게 부풀어요. 바이란은 이것 때문에 하루 118명이 찍혔어요. 사람 확인 신호(5번)를 꼭 같이 붙이세요.
2. **앱 안 브라우저**(카톡·스레드·인스타)는 쿠키가 따로 저장돼요. 같은 사람도 앱마다 1명씩 세져요. 기술적으로 합칠 방법은 없어서 안내 문구로 알려 줘요.
3. **기존 사이트에 처음 붙이면** 그날 이전 숫자는 0부터 시작해요. 기존 기록이 있는 테이블에 `human` 컬럼을 새로 추가하는 경우에는 옛날 줄을 이렇게 정리하세요: `UPDATE ... SET human = true WHERE user_id IS NOT NULL OR views > 1` (봇은 늘 1화면만 봐요).
4. **날짜 기준**은 DB 서버 시간이 아니라 `now() AT TIME ZONE 'Asia/Seoul'`이에요. 해외 리전 서버여도 한국 자정에 바뀌어요.
5. **Content-Type이 text/html인 200 응답만** 세요. 리다이렉트, 404, JSON API는 안 세요.
6. 운영자 판단(`req.user.role === 'admin'`)과 세션 비밀값(`SESSION_SECRET`)은 사이트에 맞게 바꾸세요.

## 10. Next.js / Supabase 사이트에 붙일 때 메모

- **쿠키 발급**: `middleware.ts`에서 `bv` 쿠키가 없으면 `NextResponse.next()`에 `cookies.set('bv', …, { maxAge: 400일, httpOnly: true, sameSite: 'lax', secure: true })`를 해요. 미들웨어는 Edge라 DB를 직접 쓰기 불편해요. 기록은 아래처럼 API로 보내세요.
- **방문 기록**: 서버 컴포넌트에서 기록하기보다 **`hi.js`와 비슷한 클라이언트 스크립트 하나로 합치는 게 쉬워요**.
  - 페이지 진입 시 `POST /api/v/view`(path, referrer)로 화면 연 기록을 남겨요.
  - 스크롤·터치나 6초 머묾이 있으면 `POST /api/v/hi`로 사람 확인을 보내요.
  - App Router면 `usePathname()`이 바뀔 때마다 view를 보내요. 화면 전환이 SPA라서 서버 요청이 안 생기기 때문이에요.
- **DB**: 위 SQL을 Supabase SQL 에디터에 그대로 실행하면 돼요. UPSERT는 `supabase.rpc('track_visit', {...})` 같은 Postgres 함수로 만들어서 부르면 30분 규칙까지 한 번에 처리돼요. 함수 안에 4번의 INSERT … ON CONFLICT를 그대로 넣으면 돼요.
- **보안**: 기록용 API는 service role 키로 서버에서만 DB에 써요. `site_visits` 테이블은 RLS를 켜고 공개 읽기·쓰기를 막아 두세요.
- **IP**: Vercel이면 `x-forwarded-for` 첫 번째, Railway면 `x-real-ip`를 써요.
